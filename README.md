# ccsync: чаты и память Claude Code на всех своих компьютерах

Плагин синхронизирует между вашими компьютерами то, что Claude Code хранит только локально:

- **чаты** (их можно продолжить через `/resume` на другом компьютере);
- **память** (`memory/*.md`, то, что Claude «запомнил» про проект);
- по желанию **файлы самого проекта** (CLAUDE.md, заметки), если папка проекта — git-репозиторий.

Работает в Claude Code (терминал, десктоп-приложение, VS Code) и в Orca: Orca запускает тот же Claude Code.

## Как устроено

- Данные лежат в **вашем личном приватном** git-репозитории (например, в `Personal — Имя Фамилия` в Bitbucket). Он отдельный от репозитория с плагином.
- Когда открывается сессия, плагин скачивает изменения с другого компьютера.
- После ответов Claude (не чаще раза в 10 минут) и при закрытии сессии плагин отправляет ваши изменения.
- Проекты сопоставляются по пути относительно домашней папки. `C:\Users\anna\orca\projects\x` на Windows и `/Users/anna/orca/projects/x` на Mac считаются одним проектом. Поэтому на обоих компьютерах проекты и workspaces Orca должны называться одинаково.

## 1. Что нужно на компьютере

- **Claude Code**, **Git** (на Windows это Git for Windows, он уже стоит, если работает Claude Code).
- Пустой **приватный** репозиторий для данных, например `claude-data` в своём личном проекте Bitbucket/GitHub.

## 2. Установка (один раз на каждом компьютере)

```bash
claude plugin marketplace add <ссылка на репозиторий с плагином>
claude plugin install ccsync@comrade-sync
```

Затем в Claude Code: `/plugin` → Marketplaces → comrade-sync → **Enable auto-update**.

Перезапустите Claude Code и выполните:

```
/ccsync:setup https://bitbucket.org/<workspace>/claude-data.git
```

Если откроется окно входа Bitbucket/GitHub, войдите. На втором компьютере сделайте то же самое **с той же ссылкой**.

## 3. Команды

| Команда | Что делает |
| --- | --- |
| `/ccsync:setup <ссылка>` | подключить репозиторий с данными |
| `/ccsync:now` | синхронизировать прямо сейчас, например перед тем как закрыть ноутбук |
| `/ccsync:status` | показать, настроено ли и когда синхронизировалось в последний раз |

## 4. Правила

- **Перед уходом от компьютера** напишите `/ccsync:now` или закройте сессию. Иначе последние до 10 минут работы уедут только при следующем запуске.
- **Один чат ведите на одном компьютере.** Если продолжать один и тот же чат на двух компьютерах одновременно, останется более длинная версия.
- **Память, изменённая на двух компьютерах сразу:** `MEMORY.md` склеивается автоматически. Для остальных файлов остаётся версия текущего компьютера, вторая сохраняется в `~/.claude-sync-data/conflicts/`.
- **В чатах бывают данные клиентов и ответы сервисов.** Репозиторий с данными должен быть приватным и только вашим. Никому не давайте к нему доступ.

## 5. Настройки (необязательно)

В `~/.claude/settings.json`, блок `"env"`:

| Переменная | По умолчанию | Что значит |
| --- | --- | --- |
| `CCSYNC_INTERVAL` | `600` | как часто отправлять изменения после ответов, в секундах |
| `CCSYNC_PROJECT_GIT` | `0` | `1`: ещё и pull/push самой папки проекта, если в ней git с `origin`. Изменения пушатся в основную ветку, поэтому включайте только для репозиториев с заметками, не для кода |
| `CCSYNC_DIR` | `~/.claude-sync-data` | где лежит локальная копия репозитория с данными |
| `CCSYNC_DISABLE` | `0` | `1`: временно выключить |

## Ограничения

- Не синхронизируются настройки Orca (список workspaces) и `~/.claude/settings.json`. Их настраивают на каждом компьютере отдельно.
- Удалённый чат на другом компьютере не удаляется.
- Если интернета нет, плагин ничего не ломает: он синхронизирует при следующем запуске.
