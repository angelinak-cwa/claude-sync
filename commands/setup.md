---
description: Подключить синхронизацию чатов и памяти к приватному репозиторию (один раз на каждом компьютере)
argument-hint: <ссылка на приватный git-репозиторий>
---

Подключи синхронизацию ccsync к репозиторию: $ARGUMENTS

1. Если ссылки нет, спроси её у пользователя. Это должен быть **приватный** репозиторий только для этих данных (например, `https://bitbucket.org/comradewebagency/claude-data.git` в личном проекте), не репозиторий с проектом.
2. Скрипт лежит в `${CLAUDE_PLUGIN_ROOT}/scripts/ccsync.sh`. Если путь не подставился, возьми папку плагина из файла `~/.claude-sync-state/plugin-root`.
3. Запусти через Bash: `bash "<папка плагина>/scripts/ccsync.sh" setup <ссылка>`. Если git откроет окно входа, попроси пользователя войти и дождись.
4. Перескажи результат простыми словами. Если доступа нет, скажи, у кого его попросить (владелец репозитория или админ workspace).
5. Напомни: то же самое нужно один раз сделать на втором компьютере с той же ссылкой.
